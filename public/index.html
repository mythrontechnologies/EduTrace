Import data

Import student data

Upload a CSV, map its columns to the canonical schema, check every row, then confirm. Source values are preserved with row-level provenance.

    How rows are handled

    • Required values — student name, institution code, programme, academic session and enrolment status. Rows missing any are rejected and listed.
    • APAAR identifiers are optional. Missing or malformed values are imported and raised as validation findings — never silently dropped.
    • Institution scope — rows for a different institution are skipped unless the regulator uses multi-institution mode.
    • Local checks only — format validation is not authoritative APAAR verification.
